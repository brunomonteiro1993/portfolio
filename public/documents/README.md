# Pasta de Documentos

Esta pasta contém documentos para download no portfólio.

## 📄 Currículo

### Como adicionar seu currículo:

1. **Renomeie seu arquivo PDF** para `curriculo-bruno.pdf`
2. **Coloque o arquivo** nesta pasta: `public/documents/curriculo-bruno.pdf`
3. **O download funcionará automaticamente** quando clicar no botão "Download CV"

### 📋 Especificações:
- **Formato**: PDF (recomendado)
- **Nome do arquivo**: `curriculo-bruno.pdf`
- **Nome de download**: `Bruno-Goncalves-Curriculo.pdf`
- **Tamanho máximo**: 5MB (recomendado)

### 🔗 Como funciona:
- O botão "Download CV" aponta para `/documents/curriculo-bruno.pdf`
- O atributo `download` força o download do arquivo
- O nome do arquivo baixado será `Bruno-Goncalves-Curriculo.pdf`

### ✅ Resultado:
Quando o usuário clicar no botão, o arquivo será baixado automaticamente!
